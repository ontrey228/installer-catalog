Installer Catalog

Подписанный каталог приложений и библиотек для Installer.

В актуальных сборках источник уже настроен: catalog.json и публичный ключ Ed25519. В настройках каталога можно подключить другой источник.

Каталог проверяется приложением перед показом, а загружаемые файлы сверяются по SHA-256.
